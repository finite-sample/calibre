# Calibre manuscript

The manuscript describes the implemented calibration and evaluation toolkit and
compares its defaults on the existing offline benchmark. CDI-ISO is documented
as an experimental method in the appendix. The manuscript does not claim a
clinical or economic utility improvement.

From the repository root:

```sh
uv sync --locked --all-groups
make paper-check
make paper
```

`make paper` writes `ms/build/calibre.pdf`. It requires `latexmk`, a LaTeX
installation, and the locked Python dependencies. Generated tables, numerical
macros, figure PDFs, and the input manifest live in `ms/generated/`. Both output
directories are ignored by Git and are regenerated by the build. The build reads
the committed raw results and recomputes the summaries through the existing
benchmark aggregation functions; it does not download data or rerun the grid.
`example.py` is included directly in the paper and executed by the tests.

To rerun the evidence rather than just rebuild the paper:

```sh
uv run python -m benchmarks.run --n-jobs 4
uv run python -m benchmarks.aggregate
uv run python -m benchmarks.figures
make paper
```

The default grid has seven synthetic designs and the breast-cancer dataset, ten
dataset/model configurations, eight methods, and seeds 0–29. An incomplete grid,
a duplicate record, non-finite required measurement, or inconsistent score
decomposition stops the manuscript build. Parameter choices remain in the
existing benchmark configuration and method constructors.

`benchmarks/results/environment.json` records the environment before fitting,
including the revision and hashes of numerical source files and the lockfile.
`ms/generated/manifest.json` identifies the raw CSV and carries its environment
record. A dirty revision is explicitly marked; the source hashes distinguish
such runs. Runtime is machine- and workload-dependent. The benchmark's custom
`--out` option keeps its environment alongside that output, so a quick check
cannot overwrite the full benchmark's provenance.

Use `pdftoppm -png ms/build/calibre.pdf /tmp/calibre-page` to render the compiled
pages for review. The `latexmk` target treats unresolved citations and references
as errors. Inspect page layout as well as the build log.

[REVIEW.md](REVIEW.md) records the substantive rewrite and claim audit. No package
API or fitting algorithm was changed to make the manuscript's claims hold.
